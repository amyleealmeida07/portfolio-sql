# 📂 Repositório de Scripts e Consultas SQL

Este repositório reúne scripts SQL desenvolvidos para automação, consultas, auditorias e parametrizações em sistemas de gestão, contemplando processos de ERP, Logística, Balança, Operações Agrícolas e áreas administrativas.

---

## 📁 Estrutura do Repositório

### 🚛 Balança e Logística
- Parametrização de faixas de peso
- Validação de períodos operacionais
- Controle de permissões de pesagem

### 💰 Faturamento e Vendas
- Consultas de notas fiscais de saída
- Auditoria de vendas
- Conciliação de DFe
- Pedidos em carteira

### 📊 Financeiro e Contabilidade
- Estrutura de grupos de contas
- Critérios de rateio
- Parâmetros de fornecedores
- Tipos de título

### 🌱 Gestão Agrícola
- Acompanhamento de estimativas de safra
- Atualização de estados e fases da cultura
- Consultas por talhão

### 👥 Gestão de Cadastros
- Clientes ativos
- Distribuição geográfica
- Cadastro mestre de produtos

### 🚚 Gestão de Frota e Transporte
- Informes diários de transporte
- Alocação de equipes

### 👨‍💼 Gestão e Administração
- Consultas de colaboradores
- Estrutura de cargos
- Dados admissionais

### 🔧 Gestão de Equipamentos
- Controle de frota
- Ordens de serviço
- Histórico de manutenção

### 🏭 Processos Industriais
- Registros de produção
- Consumo de insumos
- Ordens industriais

### 📦 Suprimentos e Compras
- Processos de cotação
- Ordens de compra
- Recebimento físico
- Gestão de estoque

---

## 🚀 Recursos Utilizados

- Consultas relacionais (`INNER JOIN`, `LEFT JOIN`)
- Atualização controlada de dados (`UPDATE`)
- Inserção de registros (`INSERT INTO`)
- Subconsultas e validações (`NOT EXISTS`)
- Agrupamentos (`GROUP BY` e `HAVING`)
- Boas práticas para manipulação e segurança de dados
